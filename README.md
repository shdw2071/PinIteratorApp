# Number Guesser

Приложение для угадывания числа 0000–9999 методом трёх независимых
параллельных бинарных поисков (по одному на каждую треть диапазона).

## Как получить APK без Android Studio (через GitHub Actions)

1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите содержимое этой папки в репозиторий (через веб-интерфейс
   "Add file → Upload files", либо через git).
3. Откройте вкладку **Actions** в репозитории — сборка запустится
   автоматически после загрузки файлов (или нажмите
   "Run workflow" вручную, если видите workflow "Build APK").
4. Дождитесь завершения сборки (несколько минут), откройте
   завершённый запуск (зелёная галочка), внизу страницы в разделе
   **Artifacts** будет файл `NumberGuesser-debug-apk` — скачайте его
   (это zip-архив с `app-debug.apk` внутри).
5. Распакуйте архив, перенесите `app-debug.apk` на телефон
   (например, через облако, USB или Telegram "Избранное").
6. На Android 13 откройте файл — система предложит разрешить
   установку из этого источника (Настройки → это приложение →
   "Разрешить установку неизвестных приложений"). Подтвердите и
   установите.

## Структура проекта

- `app/src/main/java/com/example/numberguesser/ThreeWayParallelSearch.kt`
  — сам алгоритм поиска (3 независимых бинарных поиска по третям
  диапазона).
- `app/src/main/java/com/example/numberguesser/MainActivity.kt`
  — экран приложения (Jetpack Compose): показывает текущие 3 числа,
  кнопки "Меньше / Угадал / Больше" для каждого, счётчик раундов
  и общего числа проверок.
- `.github/workflows/build-apk.yml` — автоматическая сборка APK
  в GitHub Actions при каждом push.
